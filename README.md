# Sentientum UX preview

Static reference mockup (desktop + mobile) of a proposed Sentientum redesign: a Home with three variants and a three-screen flow (Brief, Run, Answer), plus the design patterns behind it. No frameworks, no build step: plain HTML/CSS/JS, viewable directly through GitHub Pages.

It keeps the current look and feel (Martian Mono and JetBrains Mono, warm greys, one violet for active state, 1px rules). All data shown is example data.
